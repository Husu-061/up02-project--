НАЙДЕННЫЕ ОШИБКИ И ИХ ИСПРАВЛЕНИЯ
========================================

1. TypeError: '>' not supported between 'NoneType' and 'int'
   ПРИЧИНА: в БД поле «количество» = NULL. Функция _indicator(qty)
            пыталась сравнить None > 20 — Python не умеет.
   РЕШЕНИЕ: добавлена защита в create_product_card и _add_text_info:
            qty_safe = qty if qty is not None else 0

2. Изображение исчезало сразу после отрисовки
   ПРИЧИНА: Tkinter удаляет объект PhotoImage сборщиком мусора,
            если на него нет ссылок (классическая проблема).
   РЕШЕНИЕ: сохраняем ссылку как атрибут виджета:
            img_label.image = photo  # type: ignore

3. FileNotFoundError: 'images/beatles.png'
   ПРИЧИНА: в БД указана обложка, но файла нет в папке images/.
            PIL.Image.open() бросал исключение, приложение падало.
   РЕШЕНИЕ: функция get_product_image() с os.path.exists() +
            fallback на заглушку-фотоаппарат.

4. sqlite3.OperationalError: unable to open database file
   ПРИЧИНА: DB_PATH в config.py указывал на несуществующий файл.
            DB Browser открывал один файл, Python — другой.
   РЕШЕНИЕ: проверка через PRAGMA database_list; исправлен путь
            DB_PATH = "databases/db_variant_23.db"

5. AttributeError: no attribute 'stats_label'
   ПРИЧИНА: refresh_catalog() вызывался ДО создания stats_label
            в build_ui.
   РЕШЕНИЕ: изменён порядок в __init__:
            self.build_ui() → self.refresh_catalog()

6. Pylance: "str" cannot be assigned to "anchor"
   ПРИЧИНА: tkinter-stubs требует Literal, а не str.
   РЕШЕНИЕ: # type: ignore в строках с anchor=...

7. Tooltip накапливались и перекрывали карточки
   ПРИЧИНА: событие <Leave> срабатывало не всегда.
   РЕШЕНИЕ: единый глобальный трекер _current_tip + задержка 400 мс.

8. Пагинация не была видна (кнопки ушли за край)
   ПРИЧИНА: canvas.pack(expand=True) упакован раньше пагинации
            и съел всё место.
   РЕШЕНИЕ: правильный порядок pack():
            шапка (top) → пагинация (bottom) → canvas (expand)
